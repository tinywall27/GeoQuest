# GeoQuest 项目约束 V2

> 文档状态：V2.0
> 生效日期：2026-09-16
> 适用范围：GeoQuest 公开主题站点、内容 manifest、构建与发布校验

本文件是当前项目约束源。主题内容和实现可以演进，但不得绕过隐私、版权、来源、离线可用性和公开边界要求。

## 1. 产品与技术基线

- GeoQuest 是公开静态站点；主题使用 `/topics/:slug`，课堂模式使用同一路径附加 `?mode=classroom`，两种模式共享同一内容、数据和答案逻辑。
- 站点不创建账号、认证、班级、云端学习记录、行为画像、广告、统计、Cookie、设备指纹或第三方追踪。
- 核心课程不依赖实时外部接口。数据、字体、脚本和关键素材自托管；外部服务失败时使用同一版本的本地快照或静态替代路径。
- 使用 React、Vite 和严格 TypeScript；内容在构建阶段由 schema 校验并投影为类型安全的 `PublicTopicManifest`。Node 依赖使用 pnpm，数据工具使用 UV。
- 主题、地图、图表和较大数据按路由或交互懒加载。按需使用 3D 时必须保持核心学习路径可离线完成，并提供无 3D 的静态、二维或数值替代。

## 2. 内容契约

每个主题具备一个可探究的核心问题、一个主操作对象、结构化证据产出和解释反思。证据卡只保存结构化选择、数值、排序、路线或标注；自由文本反思不写入网站持久化数据。

公开 manifest 不得包含教材或课标源文件、扫描页、大段原文、内部页码、私有证据路径、本机路径、凭据或未获准公开的素材。教材和课标只通过原创转述及脱敏映射参与公开内容。

## 3. 发布门禁

旧版八项 `reviews` 记录在主题 manifest 中保持可选，用于兼容已有主题；它们不再构成发布条件。发布条件由一条 AI 检查记录和确定性校验组成：

```yaml
aiReview:
  status: pending | passed | blocked
  agent: content-checker
  checkedAt: YYYY-MM-DD
  evidencePath: path/to/report.md
  scope: [schema, sources, offline]
  version: 1.0.0
```

`scope` 可按任务简化，`version` 用于把通过记录绑定到主题当前版本。标记为“已发布”时，`aiReview.status` 必须为 `passed`，`aiReview.version` 必须与主题 `version` 一致，`evidencePath` 必须是仓库内相对路径且对应存在的文件。

自动校验还必须检查 ID、slug、模式路径、来源字段、来源许可、数据快照、SHA-256、公开字段边界和重复项。`dataset` 必须有许可、版本、本地快照、加工记录和校验值；`reference` 在发布时必须有核验日期；地图和媒体必须有许可、来源及本地资产。

AI 检查只能记录检查范围、结果和证据，不能生成、推断或替代法定许可、地图审查结论、再发布权或其他法律授权。来源许可和快照证据仍须按来源类型真实记录；不能伪造通过状态或证据文件。

## 4. 隐私、版权与地图

- 浏览器本机数据只允许使用 `geoquest:` 命名空间保存展示偏好、匿名结构化完成状态和 schema 版本；不得保存姓名、学校、班级、联系方式、精确位置、自由文本答案或设备标识，也不得上传这些数据。
- 仅使用原创文字、原创图形、许可清晰且允许公开再发布的来源。每项外部来源记录标题、作者或机构、原始网址、许可、获取日期、署名、修改情况和本地文件信息。
- 地图数据的开放许可不自动代表中国公开地图合规。涉及地图时记录来源、版本、审图信息（如适用）、叠加说明、离线图和可见署名；不因 AI 检查而跳过法定地图要求。
- 公开仓库和构建产物不得带教材/标准源文件、内部审核台账、私有证据或含内部源码的 source map。

## 5. 可访问性、性能与验证

- 核心操作可用键盘完成；滑杆有数值或按钮替代，地图和图表提供文字、列表或数据表替代；尊重 `prefers-reduced-motion`。
- 课堂模式适配 1366×768，站点支持 360×640 起的移动布局。高成本 3D、地图和图表不阻断文本、二维和静态证据路径。
- 首页初始应用 JavaScript gzip 后目标不超过 350 KB；主题资源按需加载，生产不依赖公共 CDN。
- 交付前运行与变更相关的 `pnpm check:boundary`、`pnpm lint`、`pnpm typecheck`、`pnpm test:run`、`pnpm build` 和内容校验；测试通过不等于授予法律许可。
