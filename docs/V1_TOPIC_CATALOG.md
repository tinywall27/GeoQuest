## 数据与模型口径

下表是实施意向，不表示来源、许可或地图已经获批：

| 主题 | V1 口径 |
|---|---|
| T003 | 原创二维教学模型；NASA 等一手材料只作事实参考，不伪装为数据快照 |
| T006 | 原创虚构高程网格、50 米等高距与三条候选路线；不使用真实地图 |
| T009 | GHS-POP R2023A 与 ETOPO 2022 的裁剪/聚合快照；世界人口资料只作旁证 |
| T022 | ERA5 1991—2020 基线与整体后移 20 天的反事实情景；保持总量一致并显著标注非预报 |
| T030 | USDA 农业资源区与作物覆盖汇总，结合本地气候/地形指标；不设唯一答案 |
| T037 | 一条西东路线的本地高程剖面与通过审核的中国地图资产 |
| T041 | 洞庭湖 1990—1994 与 2020—2024 同季节 Landsat 合成；其他水面数据只作交叉验证 |
| T047 | 四个预设地块与原创农业决策模型；气候资料只作参数依据，统计校验卡可独立关闭 |
| T060 | 2005、2014、2016、2021、2024 五节点的一手公开事实与通过审核的地图表达 |
| T065 | 受 RUSLE 思路启发的原创归一化教学模型，只输出相对侵蚀指数 |

涉及中国地图表达或遥感叠加的主题，在地图来源、审图号、裁切和送审判断完成前保持阻塞，不将待审核资产提交到公开仓库。

## 发布状态规则

主题依次经过“候选 → 已设计 → 开发中 → 待审核 → 已发布”。评分和自动测试只能辅助判断，不能把主题或来源自动设为已审核。V1 正式发布要求 10 个主题全部达到 [`RELEASE_CHECKLIST.md`](RELEASE_CHECKLIST.md) 的门禁。
