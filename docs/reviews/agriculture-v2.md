# 气候与农业 V2.0：AI 教学模拟与审查

主题 GQ-T022 / south-asia-monsoon；版本 2.0.0；2026-09-19；审查 Codex。

## 旧版试教发现与重构

实际打开旧版课堂，进入互动环节，将延迟 20 天切回 0 天，观察窗口雨量由 283 变为 538。代码审查确认原雨型为硬编码数组，但页面标注“印度中部教学样区”“1991—2020”；来源只链接 ERA5，未提供支撑该数值的观测快照。不能把这种情景继续当作真实气候基线。旧版的推迟播种、补灌和调整品种只出现在文字建议中，无法试验，也无法核对方案代价。

新版保留原路由，主题改为“气候与农业”，明确使用原创季节情景。删除真实地区与历史基线暗示；四环节工作台直接连接雨热、生长日历、逐日水量和实验记录。应对措施成为可操作变量，不再输出缺乏依据的适宜度或产量评分。

## 20 分钟模拟教学脚本

这是按课堂环节进行的 AI 情景试教，不是实测授课 20 分钟，也不证明真实班级学习效果。

| 环节 | 教师实际操作与追问 | 证据与教学用处 |
| --- | --- | --- |
| 0–3 分钟，预测 | 选择“总雨量相同，幼苗期也相同”，要求说出理由 | 初始不显示结果，保留原预测便于回顾 |
| 3–8 分钟，雨热对照 | 固定第 20 天播种、玉米示意方案、无补灌；记录原时序和晚到 20 天 | 两情景总雨量都是 320 mm，整季缺口都是 74 mm，但前 20 天缺口从 0 增至 20 mm。整季合计掩盖时段差异 |
| 8–12 分钟，播期 | 保持晚到 20 天，播种改至第 40 天；查看第 130–139 天并记录 | 早期缺口降至 0 mm，整季仍为 74 mm，低于教学阈值的生长期增至 10 天；讨论“解决一个问题是否带来另一个问题” |
| 12–15 分钟，供水与作物 | 恢复同雨季方案，分别试 60 mm 净补灌、谷子示意方案 | 补灌预算有限，玉米整季缺口降至 14 mm；作物更换会同时改变生长期和需求，不能直接推出产量与收益更好 |
| 15–18 分钟，证据解释 | 查看记录与单变量条件，再展开参考 | 参考引用实际保存的数值，不以按钮点击次数判断实验完成；同时变更播期与补灌不能作为单变量应对证据 |
| 18–20 分钟，迁移 | 回答“缺口为零能否保证丰收”；导出结果 | 回到模型范围，区分供水核算与产量预测。JSON 保存条件、预测、单位及180天水量序列 |

浏览器实际走完预测、两雨型记录、晚播、第 130–139 天、证据表和参考展开。实际查看 1366×768 投影与 360×640 手机画面；自动测试补足有限补灌、导出内容、单变量失配、模式切换、移除、重置、键盘、无 WebGL、加载后断网、无第三方请求和 Cookie、四步可访问性与溢出。

画面检查修正了图例颜色与柱色不一致，并为缺口柱补充纵轴刻度。逻辑审查修正两个延迟情景同时存在时只找第一组的配对问题；现在会寻找真正完整的单变量证据链。

## 科学原理与原创假设

已打开核对 [FAO AQUASTAT 作物与灌溉需水](https://www.fao.org/aquastat/en/data-analysis/irrig-water-use/irrig-water-requirement/)及 [FAO 有效降雨与灌溉需水](https://www.fao.org/4/s2022e/s2022e08.htm)。仅参考有效降雨、土壤储水、分阶段需水和净灌溉的基本原理；没有采用或声称通过 FAO 校准。未复制图片或图表。

- 雨型每 10 天为 0、0、20、30、50、60、70、50、30、10、0、0 mm，按天均分。完整计算180天，平移0/20/40天保留全部尾段，合计320 mm。温度每10天为18、20、23、26、28、29、29、28、26、23、20、18、15、12、10、8、6、5°C。
- 根区初始可用水20 mm、容量60 mm；80%降雨作为入水，超容量外排，其余20%不进入根区。先入水后耗水，缺水时按预算补足当日需求。补灌为净水深，不是取水总量；预算0或60 mm。
- 逐日与整季均满足：初存水＋根区入水＋净补灌＝实际耗水＋末存水＋外排；需水＝实际耗水＋供水缺口。
- 玉米示意100天，四阶段各25天，日需求2/4/5/3 mm，合计350 mm；谷子示意80天，四阶段各20天，日需求1.5/2.5/3/2 mm，合计180 mm。作物名称帮助讨论，全部系数是假设，不是种植建议。
- 15°C是统一教学阈值，不是两种作物真实损伤阈值。未模拟温度对耗水的反馈、土壤类型差异、休耕期蒸发、地下水、病虫害、产量或利润。一次雨季平移不能证明长期气候变化。

全部图形原创，无新增第三方依赖、地理地图、外部运行时 API 或持续动画。离线测试指页面已载入后断网，不宣称首次离线打开；未验证 Safari、真实手机硬件或真实班级。
