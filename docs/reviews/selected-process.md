## T014 山地降水：走读、问题与修订

脚本：教师按西风→西坡迎风→山顶2000 m与给定凝结高度1500 m→高度差500 m讲解。学生先在纸上预测东风情景，再只改风向验证。最后独立计算两组同问法高度差并说明500 m不是雨量。

发现的问题：如果把山高直接映射到“雨量”，即使标作模拟值，也容易令学生误以为降水只由高度决定；默认西风容易把“西坡”记成迎风坡的固定名称；比较时自动调整纵轴会掩盖阈值关系。

已实施修改：不输出任何雨量指标，只计算给定凝结高度以上的抬升高度；风向单独可变，迎背风名称由风向模型计算；纵轴固定0—2500 m。公开说明湿润来流、被迫越山的适用条件，以及达到凝结条件也不能保证实际降雨。

复验：西风/东风迎背风名称相互交换，几何差值均为500 m；山顶低于或等于凝结高度时差值为0，不出现负值；异常输入被限制在图的纵轴范围。两题数值分别为2000−1500和1000−500，均为500 m，读图与计算要求不突增。

教师待核验：学生是否理解东西方位、给定凝结高度与实际云底的区别；真实课堂是否需要先复习空气抬升冷却。来源核验为 NOAA 原理页的原创转述，不转载其图片：[What do leeward and windward mean?](https://oceanservice.noaa.gov/facts/windward-leeward.html)。

第二轮视觉试讲修订：集成方实屏检查指出原来流线没有箭头且缺少背风下沉路径，学生仅靠文字难以追踪气流。现已给迎风抬升线增加蓝色箭头，并补入棕色背风下沉箭头；两条路径随风向一起换边，高度端点仍来自同一山顶模型，不加入动画或雨量推断。箭头定义使用 React `useId` 隔离，避免同页对照图引用冲突。复验完成11项模型测试与目标文件 ESLint；另以应用 JSX 配置渲染东西风两图，检查4个 marker ID各不相同、4条箭头引用完整且两方向的抬升/下沉端点反转正确。修改后的实屏视觉结果由集成方继续复核，不能把此次代码渲染检查视为真实学生试教。

## T044 跨流域调水：走读、问题与修订

脚本：先板书100=40+6+54，分别标为来水、原流域留水、途中损耗与到水。只将来水改为80，由学生依次得出可调40、损耗4、到水36与缺口14。独立题再用100来水、60留水获得同样到水36，检验是否掌握顺序而非背答案。

发现的问题：仅展示“申请60”会混淆申请量与实际可调量；缺口截为0后会隐藏默认场景多到的4；来水低于生态底线时，不能宣称“先满足生态需求”已经达成。

已实施修改：实际取水同时受申请与可调余量约束；到水超过固定50需求的量单列显示；原流域来水本身不足时停止调水并明确生态目标未满足。损耗说明为未到达受水区，不暗示水从自然界消失。

复验：80来水场景40+4+36=80；100来水默认到水54、缺口0、超需求4；40来水而生态目标60时调出0，生态缺口20。扩展边界组合全部满足来水=留水+损耗+到水，调出不超过申请，能够保留的生态水不被挤占。

教师待核验：生态留水底线与真实审批标准的区别；学生是否会10%计算。10%仅为教学假设，不取自真实工程；输水损耗概念参考 USGS 的[Water-Use Glossary](https://water.usgs.gov/usgs/watuse/1995guidelines/glossary.html)检索摘要，原页正文读取未成功，不引用其数值或大段文字。

## T063 坎儿井：走读、问题与修订

脚本：教师先用100 m入口与90 m出口的概念剖面解释重力自流，说明竖井施工维护用途。相同100补给、20留存、80取水上限，暗渠假设蒸发4、到水76；只切换明渠得到蒸发16、到水64，学生指出增加的到水来自少蒸发12。独立题改补给为60，再算到水38和32。

发现的问题：只比较明暗渠到水会掩盖补给约束，易产生“暗渠就一直有水”的误解；无落差时继续显示取水会与自流解释冲突；明渠仍绘于地下会混淆结构；简单输入“补给0”时若仍宣称留存20则违反守恒。

已实施修改：加入补给为0的情景，取水受补给减留存目标与80上限双重约束；无自流落差且不设水泵时取水0；明渠对照的地表沿水道线显示，暗渠才保留覆盖及竖井，剖面高差夸大且不按比例；补给不足时分别显示真实留存量与目标未满足量，不虚构水量。

复验：默认暗渠76、明渠64，差12等于蒸发差，取水量始终相同；补给60时暗渠38、缺口12，明渠32、缺口18；补给0时取水0，无落差时100补给全部留在含水层。所有测试组合满足补给=留存+蒸发+到水，不动用历史储量。

教师待核验：真实坎儿井不能只用单期补给预测流量；水位、含水层性质与多年储量应由教师补充，页面不提供施工方案。5%和20%均是原创教学假设，不是实测值。自流及竖井原理核对了 [UNESCO World Heritage Centre](https://whc.unesco.org/en/list/1506/)正文；减少蒸发核对了 [FAO 家庭农业知识平台](https://www.fao.org/family-farming/detail/en/c/283205/)官方检索摘要，FAO原页正文读取未成功。仅作原理参考，不复制其素材，不将伊朗案例的数值或细节冒充新疆实测。
