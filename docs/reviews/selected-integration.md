# 十个精选主题：选题、模拟试讲与集成验收

日期：2026-09-22。版本：各主题 1.0.0。检查者：Codex 开发辅助 AI。

本轮从原开发矩阵选择十个主题，追加至原精选表，保留已有五个主题。原矩阵不修改。选择依据是：初中常见读图与推理困难能否拆成一个可解释、可核算、可独立检验的小任务；优先复用三个课堂母版，不同时铺开大型区域地图、实时资料或完整项目式课程。

下表中的“卡点”是设计假设，尚未观察本班学生。每主题默认 15 分钟、教师投屏、个人纸笔；页面明确先备知识、示范、单变量对照、独立题、模型边界和原理来源。实际课时与学习有效性须教师试用后判断。

## 两轮共同试讲修订

1. 初轮浏览器检查发现步骤编号对比度不足，已加深文字色；第二轮十个主题的桌面、手机 Axe 检查均无违规。
2. 走读发现迁移提示可能提前透露独立题答案。现收起模型、支架和对照记录，两题全部提交后才显示解释和深入探究，不因先答一题而提示另一题。
3. 增加检验期间回看模型或教师说明的标记；反馈后的重答单独记录。导出的模型结果明确不是学生独立计算成果，界面也不凭选择题给学生定级。
4. 学习支持与课堂/探索显示模式分开；两种模式保留同一组页面记录。记录仅在本页内存中，刷新即清除，可由教师主动导出匿名结构化 JSON。
5. 360×640 实屏复看发现整张 SVG 缩到手机宽度后文字过小。改成局部可横向滚动的图窗，保留图内字号、键盘滚动和数值表；页面本身不产生横向溢出。

## 真实试教仍待开展

本轮“试讲”是 AI/开发者模拟走读及浏览器操作，不是真实教师或学生课堂。未采集成绩、访谈或行为数据，不宣称学习提升。

建议教师按页面默认情景示范，再给单变量同类任务，最后收起帮助完成两题并核对纸笔理由。匿名记录：是否读错单位/方向、是否漏掉约束、是否能解释证据、作答时用了什么帮助。依据实际卡点调整一次一个因素；下一课用同问法新数值复查，保留独立初稿和修改条件，不把有提示重答算作独立掌握。另一位教师独立试用前，事实、答案、课时及课堂组织负担仍须核验。
