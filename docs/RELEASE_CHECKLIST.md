# GeoQuest V1 发布清单

> 自动化检查不能替代教学、地图、数据、版权、隐私或技术审核。任何未完成项都应保持“开发中”“待审核”或 `blocked`，不得发布。

## A. 仓库与公开边界

- [ ] 公开仓库不含教材/课标源文件、扫描页、办公文档、内部工作簿、`work/` 或原始加工物。
- [ ] 不含教材/课标内部页码、私有审核证据、本机路径、密钥或环境文件。
- [ ] 待审核地图、遥感、媒体和字体资产未进入提交或构建产物。
- [ ] `pnpm check:boundary` 通过；大文件、符号链接和构建产物已核对。
- [ ] 生产构建未发布含 authoring manifest、审核字段或内部源码的 source map。
- [ ] LICENSE、LICENSE-CONTENT、NOTICE 和第三方逐项署名一致。

## B. 每个主题

- [ ] 稳定 ID、slug、标题、摘要、版本和更新时间完整。
- [ ] 核心问题、唯一主操作、主题专属反馈、结构化证据和反思完整。
- [ ] 产品入口、原型和核心素养枚举正确。
- [ ] 探索模式与课堂模式使用同一内容、快照和答案逻辑。
- [ ] 课堂流程 8—15 分钟；探索流程 15—25 分钟。
- [ ] 证据可打印或导出，且不含身份、位置、设备或持久化自由文本。
- [ ] 来源和模型局限可见；示例、模拟、实测与反事实没有混淆。
- [ ] 外部服务失败、断网或 WebGL 不可用时仍有完整核心路径。
- [ ] 清除本主题进度有效；localStorage 只使用 `geoquest:`。

## C. 人工审核

- [ ] 教学审核：问题适龄、证据可回答、反馈和反思准确。
- [ ] 教材与课标审核：内部映射与原始材料已经人工核对。
- [ ] 数据审核：来源、版本、许可、加工、快照和校验值完整。
- [ ] 地图审核：来源、审图信息、版图表达、叠加和课堂裁切通过。
- [ ] 版权审核：所有公开素材允许再发布/改编并准确署名。
- [ ] 隐私审核：无账号、上传、Cookie、追踪或禁止保存字段。
- [ ] 技术审核：性能、可访问性、离线降级与浏览器验证通过。
- [ ] 每项 `approved` 都有审核人、日期和私有证据，不由脚本生成。

## D. 自动化与人工测试

- [ ] 锁文件安装、内容 schema、类型检查、Lint、单元测试和生产构建通过。
- [ ] ID/slug 唯一、引用存在、快照 SHA-256、许可和公开投影校验通过。
- [ ] 主题计算测试覆盖天文、等高线、人口、季风、农业、剖面、遥感、时间链和侵蚀模型。
- [ ] 键盘、焦点、对比度、减少动态、图表/地图替代和错误提示通过。
- [ ] 10 个主题双模式的 Playwright 关键路径通过。
- [ ] 360×640、1366×768、Chrome、Edge、Safari、Firefox 和移动端基本流程复验。
- [ ] 无 Cookie、无分析、无非白名单运行时请求；课堂模式不发起非必要请求。
- [ ] 首页初始应用 JavaScript gzip 后目标≤350 KB，其他传输预算符合约束或有批准例外。

## E. Cloudflare Pages

- [ ] Git 集成指向正确的公开仓库，生产分支为 `main`。
- [ ] 构建命令为 `pnpm run build`，输出目录为 `dist`。
- [ ] 未创建顶层静态 `404.html`；首页、主题深链接和站内 404 正常。
- [ ] CSP、Referrer-Policy、X-Content-Type-Options、Permissions-Policy 等响应头生效。
- [ ] 未启用 Web Analytics、第三方统计或 Cookie；未绑定未经确认的自定义域名。
- [ ] Preview 与 Production 均完成断网、移动端和课堂投屏复验。

## F. 正式版本

- [ ] 10 个 V1 主题全部为“已发布”，不存在用开发占位或待审核资产冒充完成。
- [ ] README、主题目录、来源页、CHANGELOG 和版本号同步。
- [ ] 从干净克隆复现安装、测试和构建。
- [ ] 标记 `v1.0.0`，记录生产地址、提交和审核归档版本。
