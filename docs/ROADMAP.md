# GeoQuest 路线图

路线图描述顺序与门禁，不把候选主题或日期当作发布承诺。任何阶段均受 [`PROJECT_CONSTRAINTS.md`](PROJECT_CONSTRAINTS.md) 约束。

## Foundation — 平台底座

- 建立 React + TypeScript + Vite 静态站、路由、设计令牌和首页信息架构。
- 建立 YAML/MDX 校验、公开内容投影、来源联合类型和懒加载注册表。
- 建立探索/课堂双模式、结构化证据卡、来源抽屉、重置/清除和本地二维码。
- 建立公开边界、内容、可访问性、外部请求、性能与端到端 CI 门禁。
- 创建公开 GitHub 仓库并连接 Cloudflare Pages 技术预览；生产构建排除未审核主题，此阶段不宣称主题已发布。

## Sprint 1 — 原创模拟与任务

- T003 如果地球不这样转：受控地球运动模型与数值测试。
- T006 等高线山地救援：虚构地形、三条路线与键盘/数值替代。
- 验证 `simulator`、`geo-challenge` 和课堂逐步控制的通用接口。

## Sprint 2 — 空间数据与反事实比较

- T009 世界人口住在哪里：裁剪人口/地形快照、分布证据与例外。
- T022 季风迟到会怎样：基线与整体推迟情景、守恒测试和风险解释。
- 完成 MapProviderAdapter、数据表降级、数据快照和许可门禁。

## Sprint 3 — 区域决策与剖面

- T030 为美国划农业带：多条件决策、不设唯一答案。
- T037 穿越中国三级阶梯：西东剖面、地势联系和地图门禁。
- 验证 `decision-lab`、`data-explorer` 和大型课堂图表。

## Sprint 4 — 遥感对比与农业选择

- T041 洞庭湖如何重获呼吸：同季节多时相对比和证据边界。
- T047 一块农田种什么：四类预设地块、三种作物和原创决策反馈。
- 完成影像共配准/替代视图、模型说明和来源抽屉复验。

## Sprint 5 — 时空协同与地表过程

- T060 一条大河如何协同上中下游：五节点时空证据链。
- T065 一场暴雨带走多少黄土：相对侵蚀模型与单调性测试。
- 验证 `story-map`、模型局限同屏提示和全站一致性。

## V1 Release — `v1.0.0`

- 10 个主题逐项完成人工教学、数据、地图、版权、隐私与技术审核。
- 完成双模式、移动端、课堂投屏、断网、可访问性、性能和跨浏览器复验。
- 清除开发占位、内部引用和待审核资产；从干净克隆复现构建。
- 发布 GitHub 版本与 Cloudflare Pages Production。

## V1 后候选

- 按教材价值、教学可操作性和来源可行性逐批复核剩余 56 个候选主题；未评审前不显示数值优先级。
- 建立带日期和离线快照的可选“实时地球”层，用于台风、火灾、沙尘、植被等时效探索，但不作为核心课程依赖。
- 评估海龟智探、气候智探、红树林智探和 GeoMuseum 的内容授权、组件复用和品牌迁移。
- 在未来大版本中重新评估 AI 提示、追问和证据评价。除非完成未成年人隐私、合规与项目约束升级，V1 与后续小版本均不预埋生成式 AI 接口。
