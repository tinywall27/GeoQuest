# 数据、地图与版权审核

> 本文定义公开仓库中的审核摘要和发布门禁。详细审核材料、原始源文件及证据路径保存在私下台账中。

## 1. 基本规则

1. 先确定来源类型，再填写对应元数据；事实参考、数据集、地图、媒体和模拟不能相互冒充。
2. 自动校验只验证字段、校验值和规则，不得把状态自动设为 `approved`。
3. `approved` 必须对应真实审核人、日期、所核版本和证据；公开仓库只保留必要的脱敏摘要。
4. 来源、许可、地图表达或再发布权不清时设为 `blocked`，不能以“教育用途”绕过。
5. 路由隐藏不是保护措施。待审核、不可公开或含内部信息的资产不得提交到公开仓库。

## 2. 来源分型

| 类型 | 必需记录 | 常见阻塞 |
|---|---|---|
| `reference` | 标题、发布方、原始网址、核验日期、引用用途 | 二手转载、链接失效、不能支持页面断言 |
| `dataset` | 标题、版本、时空范围、许可、署名、获取日、快照、加工、SHA-256 | 许可不明、无法再发布、快照不可复现 |
| `map` | 名称、来源、版本、审图信息、下载日、是否修改、署名 | 版图表达、适用范围或送审判断不清 |
| `media` | 标题、作者/机构、原始网址、许可版本、修改、署名、本地校验值 | 仅限个人使用、禁止改编、第三方权利不清 |
| `simulation` | 原创者、方法、版本、参数、局限、验证用例 | 把相对指数表述为预测或真实测量 |

## 3. 数据快照门禁

外部数据集进入主题前必须：

- 只保留回答核心问题所需的字段、时间和空间范围。
- 记录来源版本、获取日期、处理脚本版本、参数、输出路径和 SHA-256。
- 分开标记实测、汇总、插值、示例和反事实情景。
- 检查数值范围、缺失值、单位、时间顺序、聚合误差和抽样点。
- 提供不依赖外部接口的本地快照与失败提示。
- 在页面呈现数据日期、来源、加工摘要和不能支持的推论。

数据更新必须产生新快照和新校验值，复跑主题计算测试；不得就地覆盖后仍沿用旧版本记录。

## 4. 地图门禁

MapLibre 是渲染器，不代表地图自动合规。公开地图主题须逐项完成：

- [ ] 来源属于批准清单，保留地图名称、来源、版本和原始文件。
- [ ] 审图号及适用范围已由人工核验；不适用时有书面判断。
- [ ] 中国疆域、行政区、港澳台、重要岛屿与海域表达完整、准确。
- [ ] 图例、比例尺/尺度、方向、数据日期、来源和审图信息可见。
- [ ] 叠加层不会遮挡边界、重要岛屿、地名或造成版图误读。
- [ ] 课堂裁切、移动端布局和离线降级图均保持必要表达。
- [ ] 修改、重绘、概化、跨境或全国性自制地图已完成送审判断。

境外开放地图的版权许可不能替代中国公开地图合规审核。地图或遥感数据叠加也不能超出证据能力推断水质、生态成效或政策因果。

## 5. 版权门禁

原创材料优先。每项非原创材料记录权利人/机构、原始网址、许可及版本、获取日、修改内容、署名、允许的再发布/改编方式和本地校验值。

下列情况直接阻塞：

- 找不到原始发布者，只有转载页或搜索结果。
- 许可只允许个人使用、禁止公开展示/改编，或要求授权但尚未取得。
- 图片、视频、地图或字体包含未单独确认的第三方权利。
- 计划展示教材扫描页、教材插图或大段原文。
- 署名、许可链接或变更声明无法按要求呈现。

项目 MIT 与 CC BY-NC-SA 许可不会覆盖第三方材料。以具体资产旁的来源和许可记录为准。

## 6. 审核记录

内部审核记录至少包括：

```yaml
objectId: stable-object-id
objectVersion: version-or-checksum
reviewType: data | map | copyright | teaching | privacy | technical
status: unreviewed | initial | approved | blocked
reviewer: private-reviewer-id
checkedAt: YYYY-MM-DD
evidence: private-evidence-reference
notes: conclusion-and-limitations
```

公开投影可以显示审核状态、日期、版本和非敏感结论，但不得暴露审核人身份、内部证据路径、本机路径或私有源文件。

## 7. V1 高风险主题提醒

- 世界人口、三级阶梯、湖泊遥感和长江主题涉及地图/空间表达，资产进入公开仓库前先通过地图门禁。
- 洞庭湖主题只比较同季节水陆边界等影像可见事实，不把影像变化直接归因为治理，也不推断水质。
- 农田选择和黄土侵蚀采用教学模型，输出适宜性或相对指数，不表述为业务建议、精确产量或泥沙预测。
- 季风推迟情景是保持清晰假设的反事实教学情景，不是历史事实或天气预测。
