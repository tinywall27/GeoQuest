# GeoQuest 产品规划

> 状态：V1 开发基线
> 更新：2026-08-09

## 1. 产品定位

GeoQuest · 地理智探是“教材驱动的地理互动探索平台”，副标题为“从教材出发，探索真实世界”。它不是电子教材或文件资源库，而是把教材中适合观察、比较、实验、推理与决策的内容转化为可独立访问的互动主题。

每个主题必须让学生完成一条可见的学习链：

```text
核心问题 → 主要互动 → 证据产出 → 解释反思
```

主题数量不是成功指标。一个主题应有唯一主操作对象、清晰反馈、可核对证据和明确局限，并能在课堂展示与课后探索中复用同一事实和数据快照。

## 2. 用户与使用情境

- 七、八年级学生：按引导自主探索并形成结构化证据。
- 初中地理教师：使用课堂模式投屏、控制步骤、显隐结论和发起讨论。
- 内容与开发团队：以稳定内容模型持续增加或维护主题。
- 审核人员：分别完成教学、课标、教材、数据、地图、版权、隐私与技术门禁。

V1 不提供登录、班级、作业、成绩、云端学习记录、AI、分析统计或后台管理。

## 3. 信息架构

### 3.1 六个产品入口

| 入口 | 学习行为 | 典型内容 |
|---|---|---|
| 教材探索 | 沿卷册、章节和问题线索发现主题 | 四册教材、跨章节融合主题 |
| 地图实验室 | 叠加、定位、测量、比较空间分布 | 人口、地形、区域联系 |
| 数据实验室 | 筛选、比较、观察时间变化并解释 | 人口、气候、农业与发展数据 |
| 地球实验室 | 改变变量并观察系统响应 | 地球运动、季风、地表过程 |
| 区域探索 | 综合区域条件、联系与选择 | 国家、流域、农业与区域发展 |
| 地理挑战 | 在限制条件下完成任务并说明理由 | 路线、判断、方案与情境挑战 |

产品入口是发现路径，不是交互类型。同一主题可以出现在多个入口，但只有一个主交互原型和一个规范地址。

### 3.2 八类互动原型

| 稳定键 | 中文标签 | 核心动作 |
|---|---|---|
| `simulator` | 变量模拟 | 改变一个或一组受控变量，观察结果 |
| `map-explorer` | 地图探索 | 操作图层、地点、距离或空间关系 |
| `story-map` | 时空故事 | 沿时间或路径推进，连接事件与空间 |
| `data-explorer` | 数据探索 | 比较指标、时间和区域并形成证据 |
| `image-explorer` | 遥感对比 | 同位置、同尺度比较不同时相影像 |
| `compare` | 区域比较 | 在一致维度下比较对象及差异原因 |
| `decision-lab` | 决策模拟 | 在约束和取舍中形成可解释方案 |
| `geo-challenge` | 地理挑战 | 完成有明确反馈的综合任务 |

### 3.3 主要页面

- 首页：品牌主张、四册教材、六个入口、继续探索、本周主题和热门实验。
- 教材页：卷册与章节脉络，以及关联主题。
- 主题目录：按卷册、章节、核心素养、产品入口和原型筛选。
- 主题页：规范地址 `/topics/:slug`，课堂模式附加 `?mode=classroom`。
- 实验室/挑战入口页：按学习行为组织主题，不复制主题内容。
- 课堂使用指南、来源与方法、设置和站内 404。

## 4. 双模式体验

探索模式保留完整引导、提示、来源、证据卡和反思。课堂模式使用更大字号、更少控件、逐步控制、重置、结论显隐、全屏和本地二维码；来源、审图号、关键风险和模型局限始终可见。

两种模式共享一个清单、交互逻辑和数据快照。课堂模式不发起非必要外部请求，也不是教师后台。

## 5. 内容规模与 V1

长期候选池共有 66 个主题。V1 只承诺 [`V1_TOPIC_CATALOG.md`](V1_TOPIC_CATALOG.md) 中的 10 个主题，其余 56 个保留为后续候选，不展示未经逐项审核的伪精确评分。

V1 主题覆盖八类基础原型和地图、数据、模拟、遥感、决策等关键技术路径。所有 10 个主题都必须完成双模式、结构化证据、离线降级、可访问性替代和人工发布门禁，才形成 `v1.0.0`。

## 6. 设计方向

- 视觉：采用“地理考察手帐”方向，以暖纸张、深青绿、地图蓝、植物绿和任务黄构成主色；用真实或原创可审核资产、统一图标与数据驱动画面建立野外探索感，避免成人化后台、传统资源门户和幼稚卡通风。
- 首页主张：“探索地球，而不只是阅读地理”。
- 内容：问题和证据优先，正文简洁；来源和局限可随时查看。
- 交互：学生主动操纵变量或证据，而不是观看不可控制的动画。
- 组件：约 80% 主题由通用原型和组件构建，约 20% 保留主题专属表达。

参考的是交互范式而非页面复制：ArcGIS StoryMaps 的滚动叙事、National Geographic MapMaker 的问题驱动图层探索、PhET 的可控变量实验、HHMI EarthViewer 的时间同步、Gapminder 与 Our World in Data 的数据比较、NASA Worldview 的时相影像，以及 Earth Nullschool 的动态地球系统表达。

## 7. 成功标准

- 学生能在不依赖教师口头补充的情况下理解核心问题和操作。
- 课堂主流程 8—15 分钟，课后完整探索 15—25 分钟。
- 每个主题形成可打印或导出的结构化证据，不持久化自由文本。
- 核心流程在断网或第三方服务失败时仍可完成。
- 10 个主题通过教学、数据、地图、版权、隐私、可访问性和技术审核。
- 首页初始应用 JavaScript gzip 后目标不超过 350 KB，地图、图表和主题模块按路由加载。

## 8. V1 后方向

- 逐批复核 56 个候选主题，而非一次性公开全部清单。
- 增加带日期、可回退的“实时地球”可选层，但不改变静态快照优先原则。
- 评估海龟智探、气候智探、红树林智探和 GeoMuseum 的内容迁移与统一入口。
- AI 仅在未来大版本重新完成未成年人隐私和合规评估后考虑，可研究提示、苏格拉底式追问和证据评价；V1 不预埋接口或占位实现。
